# cedoajans-medya

Cedo Ajans Instagram hesabinda paylasilacak gorsel ve videolar.
Dosyalar GitHub Pages uzerinden herkese acik baglantiyla sunulur; paylasim araclari (Metricool, Windsor.ai) bu baglantilari kullanir.

Klasorler:
- `gonderi/` akis gonderileri (1080x1350)
- `story/` hikayeler (1080x1920)
- `reels/` videolar
- `test/` baglanti testleri
